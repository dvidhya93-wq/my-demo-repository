# Exporting a Scan Report

## Overview
This guide explains how to export a scan report from the Reports section.

## Prerequisites
- User must be logged in

## Steps
1. Navigate to the **Reports** section
2. Select the required scan
3. Click **Export**

## Output Formats
- PDF
- CSV

## Troubleshooting

### Export Failure
Export may fail due to:
- Timeout
- Large data size

**Resolution:**
- Retry the export
- Reduce the amount of data and try again
