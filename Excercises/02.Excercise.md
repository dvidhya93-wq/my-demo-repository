# Exporting a Report in Appscan

## Overview
This guide explains how to login, run a security scan, and export the scan reports in Appscan.
## Prerequisites
- Access to the Appscan website
- Valid email and password
## Steps
### Log in to Appscan
- Open the Appscan application
- Enter your email and password
- Click **Login**
### Start a scan
- Click **New Scan**
- Select the application to scan
- Start the scan
### Export a scan report
- Click **Export**
- Select the data range.
- Go to the **Dashboard>Reports**
- Locate the scan report and Click **Download**

## Output Formats
- Go to **Downloads**
- Select **SaveAs**
- Select the output format as **.pdf** or **.csv**
- Click **OK**
The scan report is downloaded in **pdf/csv** formats.

## Troubleshooting
### Export Failure
If the export fails:
- Go to the **Dashboard**
- Locate the failed export report
- Click **Retry**

### Server Errors
Error Code: **500**

Cause: Your session expired due to inactivity.

Action: Sign in again to continue.


Error Code: **429**

Cause: The data set is too large.

Action: Reduce the amount of data and try again.
