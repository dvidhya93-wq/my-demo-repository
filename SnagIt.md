# SangIt
## Why to Use Snagit When Free Tools Exist?

Free tools like snipping tool and green shot has very limited features like highlighting, inserting shapes and crop. It requires other external tools like Paint or editing tools to make changes to the images. Whereas SnagIt has advanced features to Capture an image or video or scroll capture. It also has a lot of editing options like adding step numbers, blurring sensitive data and sharing the image or video to other applications.



## Write a paragraph about Sangit (what, why, use cases, and limitations)
### What:
SnagIt is a screen capture, video record and scroll capture and edit tool which has multiple options to edit the pictures, videos or scroll capture.
#### SnagIt contains the following features for images:

 1. Add the callouts
 1. Add Arrows
 2. Add Step Numbers or Letters to an Image
 2. Blur sensitive data
 2. Edit/remove the data in an image
 1. Remove a section from the image
 5. Add border
 7. Easy share to various applications
 5. Share Image or Video Link 

#### SnagIt contains the following features for videos:
 - To trim the video
 - Share Video directly or as Link 


### Why:

To create clear, consistent visual documentation in software projects. To annotate workflows, standardize screenshots and quickly update UI changes (improving user clarity and reducing support queries)

### Use cases:
* Installation guides, configuration manuals (Step by step guides, add numbered steps, blur confidential data)

* Release notes documentation (to capture before Vs After screens)

* Scroll capture for long dashboards

* Cross functional collaboration (to give annotated feedback to product and engineering teams, improving communication)

#### Limitations:
###### Manual re-capture is required when UI changes.
###### Version control cannot be done.
###### It is not a collaborative platform.
###### Licensing cost - Its a paid tool, not for small groups.
