# Running a Scan in AppScan

## Overview
This guide explains how to install AppScan, log in, and run a security scan on your application.

## Prerequisites
- Access to the AppScan website
- Valid email and password

## Steps

### 1. Install AppScan
- Download the installer from the AppScan website
- Run the installer and follow the setup instructions

### 2. Log in to AppScan
- Open the AppScan application
- Enter your email and password
- Click **Login**

### 3. Start a Scan
- Click **New Scan**
- Select the application to scan
- Start the scan

## Troubleshooting

### Scan Failure
If a scan fails:
- Go to the **Dashboard**
- Locate the failed scan
- Click **Retry**

### Server Errors
- Error Code: **500**
- Cause: Server is temporarily unavailable
- Action: Wait and retry the scan
